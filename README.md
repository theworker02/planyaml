# planyaml

Plan URLs and yaml query parts with stable normalization.

**Site:** https://theworker02.github.io/planyaml/

## Install / run

```bash
git clone https://github.com/theworker02/planyaml.git
cd planyaml
node src/cli.js
node --test
```
